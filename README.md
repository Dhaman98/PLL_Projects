# STM32 PLL and Clock Configuration Projects

System clock configuration projects on STM32 using PLL
and external oscillator (HSE) clock sources.

## Projects
- `PLLSYSCLK/` — PLL-based system clock configuration
- `HSESYSCLKusing8Mhz/` — System clock from 8MHz HSE oscillator
- `PLL_SYSCLKUsingHSE/` — PLL with HSE as input clock source

## Concepts Covered
- RCC clock tree configuration
- PLL multiplier and divider settings
- HSE vs HSI clock sources
- System clock switching and verification

## Hardware
STM32 Nucleo board (ARM Cortex-M4)

## Tools
STM32CubeIDE, GDB, oscilloscope
